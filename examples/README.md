# Example diagrams

Each file is a diagram saved from [Diagramium](https://www.diagramium.com) (**File → Save**). Open one there (**File → Open**) to change it, then upload it to a panel or regenerate the demo dashboards with `npm run demo:dashboards`.

| File                         | Editor              | Demo dashboard                    |
| ---------------------------- | ------------------- | --------------------------------- |
| `ecommerce-platform.json`    | System architecture | Online store — the whole platform |
| `checkout-internals.json`    | Flowchart           | Inside Checkout — POST /checkout  |
| `kubernetes-cluster.json`    | System architecture | Kubernetes cluster — prod-eu-1    |
| `data-pipeline.json`         | System architecture | Data pipeline — events to insight |
| `production-deployment.json` | Network             | Production deployment             |
| `hardware-rack.json`         | Network             | Server room — rack A              |
| `docker-host.json`           | System architecture | Docker host — docker-host-1       |
| `microservices.json`         | System architecture | Online store — microservices      |

What each dashboard demonstrates: [docs/examples.md](../docs/examples.md).
